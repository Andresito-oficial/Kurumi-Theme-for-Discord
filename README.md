# Kurumi-Theme-for-Discord

# Tokisaki Kurumi — BetterDiscord Themes

Temas de [BetterDiscord](https://betterdiscord.app/) basados en la paleta de
Tokisaki Kurumi (*Date A Live*), sincronizados con el esquema de color del sistema
y con los temas GTK de Zaphkiel.

## Contenido

- `themes/` — Temas de BetterDiscord (`.theme.css`)
- `wallpapers/` — Imágenes de fondo usadas por los temas

## Temas disponibles

| Tema | Archivo | Modo |
|---|---|---|
| Tokisaki Kurumi Dark | `tokisaki-kurumi-dark.theme.css` | Oscuro |
| Tokisaki Kurumi Light | `tokisaki-kurumi-light.theme.css` | Claro |

Ambos temas comparten la misma estructura de variables CSS: los paneles principales
son semitransparentes para dejar ver el wallpaper, mientras que los popups, menús
contextuales, modales y tooltips se mantienen sólidos para garantizar la legibilidad.
